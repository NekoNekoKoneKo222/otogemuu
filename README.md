# PULSE REQUIEM（FNF風音ゲー × 弾幕シューティング）

ブラウザで遊べる、4形態のオリジナルボス戦ゲームです。**音ゲーは敵の攻撃を防ぐための操作**で、ボスへのダメージはプレイヤー自身の弓と剣で与えます。

- プレイ: https://pulse-requiem-otogemuu.onrender.com/
- ソース: https://github.com/NekoNekoKoneKo222/otogemuu
- 追加ライブラリなしで `dist/index.html` 単体動作。

## 操作

| 入力 | 動作 |
|---|---|
| ← ↓ ↑ → | FNF風4レーンの敵ノーツに対応して防御 |
| W / A / S / D | プレイヤーの移動 |
| **Space** | **弓で遠距離攻撃**（ノーツ判定と無関係） |
| 左クリック | 剣で近距離攻撃（ノーツ判定と無関係） |
| Shift | 無敵ダッシュ（クールダウンあり） |
| P / 画面右のPAUSE | 一時停止を試みる |

## 4つの形態

1. **第一形態**：敵が4レーンとプレイヤー頭上にノーツを落としてくる。通常ノーツを適切なタイミングで押すと防御できる。
2. **第二形態**：赤色のダメージノーツが追加。間違えて押すとダメージ。チャートが速くなる。
3. **第三形態**：ブルーノーツとオレンジノーツが追加され、弾幕と同時に処理する。青は押さないか静止、橙は移動しながら押す。
4. **最終形態**：触れる／押すと即死するノーツ、タイミングよくShiftでダッシュする必要がある巨大落下攻撃、画面いっぱいの弾幕。

ノーツをうまく処理するとスコアとコンボが上がり、敵の攻撃を回避できます。**ノーツの精度によってプレイヤーの弓や剣のダメージが増える仕組みはありません。**

オリジナルの130 BPMシンセBGMはWeb Audio APIで自動生成。楽曲に合わせて形態が変わります。ハイスコアはブラウザのlocalStorageに保存されます。
